FAITH.CO — SITE DE LOJA (FRONT-END)

COMO ABRIR
1. Extraia faith_co_site.zip.
2. Abra index.html no navegador para testar.
3. Para publicar, envie os 3 arquivos (index.html, styles.css, script.js) para uma hospedagem estática, por exemplo GitHub Pages, Netlify ou Vercel.

ANTES DE PUBLICAR
- Abra script.js e substitua WHATSAPP_NUMBER pelo número real no formato internacional, somente dígitos. Exemplo: 5521991234567.
- Revise nomes, preços, descrições e produtos no array PRODUCTS no início de script.js.
- Os produtos usam ilustrações CSS temporárias, não fotos reais. Substitua-as por fotos próprias dos produtos para vender de verdade.
- Informe políticas reais de entrega, troca/devolução, privacidade, termos de uso, CNPJ/dados do vendedor e canais de atendimento conforme aplicável.
- Confira preços, tamanhos, estoque, frete e prazos antes de receber pedidos.

O QUE FUNCIONA NESTA VERSÃO
- Layout responsivo para celular e computador.
- Catálogo de demonstração, busca e filtros.
- Sacola com quantidades, remoção e subtotal, guardada no navegador.
- Montagem do pedido e redirecionamento para WhatsApp depois de configurar o número.

O QUE AINDA PRECISA PARA UMA LOJA COMERCIAL COMPLETA
- Pagamento online (Pix/cartão), integrado a um provedor como Mercado Pago ou Stripe.
- Cálculo de frete, estoque e logística.
- Painel administrativo seguro para cadastrar produtos e gerir pedidos.
- Cadastro real de newsletter e banco de dados.
- Domínio próprio, HTTPS e páginas legais revisadas.
Esta entrega é uma base funcional de vitrine e pedido por WhatsApp; não processa pagamentos nem confirma estoque automaticamente.
